# 版本规则与兼容范围

## 版本号规则

从 0.35 起，版本号 `主版本.次版本.修订版本` 含义如下：

| 位 | 含义 |
| --- | --- |
| 主版本 | 是否还能连接旧客户端。不再兼容连接时升主版本，在此之前会先发布 `0.99.x` 过渡版本 |
| 次版本 | 可以改变非核心功能；核心功能只在有条件兼容时才改变。相邻次版本的客户端必须能够连接 |
| 修订版本 | 保持兼容 |

建议不要跨越过多版本一次升级，升级前阅读 [CHANGELOG](https://github.com/djylb/nps/blob/master/CHANGELOG.md)。

## 旧版 npc 的连接范围

`npc -version` 输出的 `Core version` 是协议版本。当前支持的协议版本为 `0.26.0` 到 `0.34.0`：

| `nps.conf` 设置 | 可连接的最低协议版本 |
| --- | --- |
| `secure_mode=true`（示例配置） | `0.33.0` |
| `secure_mode=false` | `0.26.0` |

服务端启动日志会打印当前允许的最低版本。

旧版客户端连接新版服务端时，可能需要启动参数 `-proto_version=0`；新版 npc 也可以用 `-proto_version=<0-8>` 使用较旧的协议，序号依次对应上面的 `0.26.0` … `0.34.0`。

## 依赖 npc 版本的功能

能连接不代表所有功能可用：

| 功能 | 要求的 npc |
| --- | --- |
| 服务端下发健康检查 | 0.35.0 及以上；更旧的 npc 不会收到检查，服务端继续接受它按自身配置发来的上报 |
| 网页远程更新客户端 | 0.34.9 及以上 |
| P2P（访问端和提供端） | 0.34.8 及以上 |
| 多实例按实例路由 | 0.32 及以上；更旧的 npc 没有稳定的实例标识，按 `bridge_select_mode` 选择 |
