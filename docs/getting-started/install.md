# 安装指南

NPS 推荐使用 **Docker 部署**，也支持脚本安装、发布包和源码编译。

| 方式 | 适用 |
| --- | --- |
| [Docker](/getting-started/install-docker.md) | 推荐；镜像默认禁止远程更新 |
| [脚本](/getting-started/install-script.md) | Linux、macOS、FreeBSD 等，不支持 Windows |
| [发布包](/getting-started/install-release.md) | 所有平台；可手动控制版本 |
| [Windows](/getting-started/install-windows.md) | Windows 10/11；Windows 7 使用 `old` 包 |
| [Android 与 OpenWrt](/getting-started/install-platforms.md) | 专用应用和软件包 |
| [源码编译](/getting-started/install-source.md) | 需要自行构建 |
