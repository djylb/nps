# 管理页面说明

网页管理界面的每个页面、分组和主要字段。页面和按钮的名称按简体中文界面写；右上角可切换语言和深浅色主题。操作步骤见各场景教程，这里只说明“这个字段是什么意思”。接口对应关系见 [Web API](/reference/web-api.md)。

管理员账号由 `nps.conf` 的 `web_username`、`web_password` 决定。开启 `allow_user_login` 后，客户端用户（在“客户端”里设置了“Web登陆用户名”的客户端）也能登录，只看到自己的客户端、隧道和域名转发，没有“全局参数”和“封禁管理”。

## 左侧菜单

| 菜单 | 内容 | 谁能看到 |
| --- | --- | --- |
| 仪表盘 | 服务端概况 | 所有人（内容不同） |
| 客户端 | 客户端列表与设置 | 所有人 |
| 域名转发 | 按域名转发的网站 | 所有人 |
| TCP 隧道 | 一个服务端端口转发到内网 TCP 服务 | 所有人 |
| UDP 隧道 | 同上，UDP | 所有人 |
| 混合代理 | 同一端口提供 HTTP 和 SOCKS5 代理 | 所有人 |
| 点对点访问 | 需要访问端的私密隧道 | 所有人 |
| 虚拟后端 | 客户端上报的虚拟服务，只读 | 所有人 |
| 全局参数 | 全局名单、全局限速、重载配置、Geo 数据、配置导出导入 | 仅管理员 |
| 封禁管理 | 登录失败封禁记录 | 仅管理员 |
| 使用说明 | 打开在线文档 | 所有人 |

顶栏有深浅主题切换、“恢复默认页面设置”（清掉列的显示、排序等本地记忆）和语言切换。列表页的表格都可以搜索、排序、选择显示哪些列、展开一行查看详情。

## 仪表盘

管理员看到：

- 客户端总数、在线客户端、当前连接数、在线时间。
- 配置信息：监听的端口、桥接模式、HTTP / HTTPS 端口、流量数据持久化、日志级别、P2P 地址等，可以折叠。
- 系统信息（`system_info_display` 开启时）：处理器、内存、负载、TCP/UDP 已建立连接数、流入流出带宽，以及相应的图表。
- 开启在线更新时，有更新服务端的入口。

客户端用户看到服务端 IP、连接端口、服务端版本、最低支持版本和已登记 IP。

## 客户端

### 客户端列表

列表上方显示“服务端转发”的流入、流出流量与当前速率（仅管理员；“流入”是访问者发往客户端的流量，“流出”是客户端返回访问者的流量），按钮有“新增”和“清空流量”。

常见列和详情项：

| 名称 | 含义 |
| --- | --- |
| 唯一验证密钥 | 客户端连接服务端用的密钥（命令里的 `YOUR_VKEY`） |
| 状态、在线、离线 | 客户端当前是否连着；状态也表示是否启用（开放/关闭） |
| 模式、版本 | 客户端的连接方式和版本；有新版本时可点“更新” |
| 网速、上行网速、下行网速 | 当前速率 |
| 入口流量、出口流量、上下行流量、实际消耗 | 流量统计口径见[限制与统计](/reference/features-limits.md) |
| 流量限制、时间限制、带宽限制、剩余流量、剩余时间 | 配额，见[限制与统计](/reference/features-limits.md) |
| 最大连接数、当前连接数、最大隧道数 | 连接和隧道数上限与当前值 |
| 客户端地址、本地地址 | 客户端从哪个地址连上来，以及它自己报告的本地地址 |
| 加密、压缩 | 该客户端与服务端之间是否加密、用什么压缩 |
| 下行整形统计 | 启用流量整形时的生效状态、补充字节、等待时长、注入记录数、异常数 |

每行“查看”列有三个按钮：“隧道”和“域名”（跳到该客户端的隧道、域名列表）、“启动命令”。“选项”列有编辑；管理员还有暂停/启用和删除。在线客户端旁有“踢下线”（让客户端断开，配置保留，可重连）和“更新”（请求客户端自我更新，管理员可用）按钮，列表上方有“Ping 检测”。

### 新增客户端、编辑客户端

字段分组，右上角“全部展开/全部收起”可展开所有分组：

**基本信息**

| 字段 | 含义 |
| --- | --- |
| 备注 | 自己看的名字 |
| 唯一验证密钥 | 客户端连接用的密钥，不填自动生成 |

**传输设置**

| 字段 | 含义 |
| --- | --- |
| 压缩 | 该客户端与服务端之间的压缩：不压缩，或 snappy、zstd、flate |
| 加密 | 是否加密；底层传输已经是 TLS、QUIC、WSS 时可以关 |
| 下行调度、上行调度 | 一个会话有多条连接时，数据怎么分配（每条连接固定走一条、整个会话走一条、按包打散等）。上行调度“跟随客户端配置”表示以 npc 本地设置为准 |
| 高级设置里的流量整形 | 对该客户端启用流量整形；服务端配置了整形来源才生效 |

**配额与有效期**（编辑页多一个“清空流量统计”）

| 字段 | 含义 |
| --- | --- |
| 流量限制 | 总量上限，带单位；留空不限 |
| 时间限制 | 到期时间，日期格式随意，留空不限 |
| 带宽限制 | 上下行合计的速度上限，KB/s；留空不限 |
| 最大连接数、最大隧道数 | 留空不限 |

这几项输入框只有在 `nps.conf` 里打开对应的 `allow_*_limit`（流量、时间、带宽、连接数、隧道数）时才显示，见[限制与统计](/reference/features-limits.md)。

**访问控制与认证**

| 字段 | 含义 |
| --- | --- |
| 允许客户端通过配置文件连接 | 是否允许用配置文件方式连接，配置文件写法见[npc 配置文件](/reference/npc-config.md) |
| Basic 认证用户名、密码 | 给该客户端的 SOCKS5、HTTP 代理和域名转发设的账号 |
| 名单优先级、IP 黑名单、IP 白名单 | 谁能访问这个客户端下的服务，见[访问控制](/guide/server/access-control.md) |
| 仅允许已登记的 IP | 访问者必须先登记 IP |

**Web 管理账号**：给客户端用户登录管理界面用的“Web登陆用户名”、“Web登陆密码”和“Web登陆TOTP密钥”（两步验证）。

**IP 登记设置**：“登记口令”（点“生成”随机产生）、“登记链接”和“登记最长有效期（小时）”，留空或 0 为 2 小时。

### 启动命令

每个客户端、每条点对点访问隧道都有“启动命令”页：按当前服务端的连接地址，生成可直接复制的 `npc` 命令、启动链接和系统服务安装命令。页面上可以选“临时启动”或“安装为服务”，选连接方式，指定连接名称，并把调整后的表单保存下来；清空保存的表单则恢复默认。用法见[启动链接与多条连接](/guide/client/launch.md)。

## 域名转发

### 域名列表

列有域名、客户端 ID、目标、模式、路径、路径重写、自动 HTTPS、TLS 直通、TLS 终止、自动 CORS、兼容模式、自动证书、请求头与返回头修改、重定向地址、证书与密钥、各项流量与速度、“启用状态”（已启用/已暂停）和“客户端状态”（在线/离线）。每行可编辑、删除、暂停/启用，以及单独切换各项开关。

### 新增域名、编辑

**基本信息**：客户端 ID、备注、域名（可写 `*.proxy.com` 泛域名）、模式（所有、http、https）。

**目标与路径**

| 字段 | 含义 |
| --- | --- |
| 目标类型 (HTTP/HTTPS) | 内网目标是 HTTP 还是 HTTPS |
| 目标 (IP:端口) | 内网目标，分行填写多个即负载均衡 |
| URL 路由 | 只转发该路径前缀下的请求，留空不限 |

**HTTPS 与证书**：自动 HTTPS (301)、TLS 直通（由后端解密）、TLS 终止（解密转发）、自动证书、HTTPS 证书和密钥（PEM 文本或文件路径，可拖拽填写）。输入域名后，页面会提示可复用的已有证书。各项含义见[站点与 HTTP](/reference/features-http.md)。

**路由与请求响应**：URL 重写、重定向地址（307）、请求域名信息修改（改写发往目标的 Host）、请求头部信息修改、返回头部信息修改（一行一个 `名称: 值`，可用占位符）、自动修复 CORS、兼容模式。

**传输设置**：压缩算法，默认“跟随客户端”，也可指定算法或“不压缩”。

**后端设置**：代理到服务器本地、代理协议（Proxy Protocol，关闭、V1、V2）、健康检查（检查方式、检查路径、间隔、超时、失败阈值）。

**账号认证**：密码认证，一行一个 `用户名=密码`，留空不启用。

**访问控制**：名单优先级、IP 黑名单、IP 白名单、仅允许已登记的 IP。

**流量与有效期**：最大连接数、上行限速、下行限速（KB/s，0 不限）、流量限制、时间限制。

## 隧道页面

TCP 隧道、UDP 隧道、混合代理、点对点访问四个页面用同一套列表和表单，新增页上方的“模式”选择决定显示哪些字段，页面里还有对应的“使用场景”示例。点对点访问的表单没有目标、服务端端口和 IP 名单字段，访问控制只有“目标访问控制”。

### 列表

列有客户端 ID、备注、模式、服务端端口、目标 (IP:端口)、各项流量与速度、连接数，以及三个状态：“启用状态”（已启用/已暂停）、“监听状态”（监听中/未监听）、“客户端状态”（在线/离线）。目标指向没人上报的虚拟后端时显示“目标服务不可用”。点对点访问隧道的列显示“唯一标识密钥”（访问端凭它连接）和中继流量、直连流量。每行可编辑、删除、暂停/启用、查看“启动命令”（点对点访问）。

### 新增、编辑隧道

**基本信息**：模式（TCP 隧道、UDP 隧道、混合代理、点对点访问）、客户端 ID、备注。

**监听与目标**

| 字段 | 含义 |
| --- | --- |
| 服务端 IP | 在服务端哪个地址上监听，例如 `0.0.0.0` |
| 服务端端口 | 留空自动分配；TCP、UDP 可填端口范围如 `8000-8100,9000`，每个端口新建一条隧道 |
| 目标 (IP:端口) | 内网目标，分行填写多个即负载均衡（只有 TCP 隧道支持）；勾选“代理到服务器本地”后可以只写端口 |
| 唯一标识密钥 | 点对点访问用，访问端凭它连接 |
| 启用 HTTP 代理、启用 Socks5 代理 | 混合代理里开哪几种 |

**传输设置**：压缩算法，默认跟随客户端，也可指定或“不压缩”。

**后端设置**：代理到服务器本地、代理协议（Proxy Protocol）、健康检查（仅 TCP 隧道，字段同域名转发）。

**账号认证**（混合代理）：密码认证，一行一个 `用户名=密码`，留空不启用。

**访问控制**：名单优先级、IP 黑名单、IP 白名单、仅允许已登记的 IP，以及“目标访问控制”（混合代理、点对点访问）：选关闭、白名单或黑名单，再填目标访问控制条目；对点对点访问来说，它决定访问端能自己指定哪些目标，关闭时不限制访问端的目标。条目写法见[混合代理](/guide/tunnels/mixed-proxy.md)。

**流量与有效期**：最大连接数、上行限速、下行限速、流量限制、时间限制；编辑页多一个“清空流量统计”。点对点访问的限速只对经服务端中继的流量生效。

各类隧道怎么选、怎么用见 [按用途选隧道](/guide/tunnels/README.md)。

## 虚拟后端

由客户端上报的虚拟服务列表，只读：展示每个虚拟后端的类型和标识（可复制，用于隧道目标 `service://<标识>`）。不能在网页新增或修改，用法见[虚拟后端](/guide/tunnels/virtual-backend.md)。

## 全局参数

仅管理员。

| 分组 | 内容 |
| --- | --- |
| 名单优先级、全局 IP 黑名单、全局 IP 白名单 | 相当于 nps 前面的防火墙，作用于所有进入 nps 的连接，包括管理界面（P2P 探测端口除外）。被拒绝的地址连管理界面也打不开，修改前确认不会把自己挡在外面 |
| 全局最大转发连接数 | `0` 不限，并显示当前占用 |
| 全局带宽限制 (KB/s) | 所有客户端转发流量合计的上限，`0` 不限 |
| 保存 | 保存以上设置 |
| 重新加载配置 | 重新读取 `nps.conf`，与 `SIGUSR1` 相同；结果分“已生效”“需要重启”“失败”三栏列出，见[运维](/guide/server/operations.md) |
| Geo 数据 | `geoip.dat`（名单里的 `geoip:` 规则用）和 `geosite.dat`（目标访问控制里的 `geosite:` 规则用）的状态与“更新”按钮 |
| 配置导出导入 | “导出配置”下载含密钥的 JSON，“导入配置”选择文件导入，见[备份与恢复](/guide/server/backup.md) |

## 封禁管理

仅管理员。列出登录失败被封禁的对象：封禁对象、类型（IP 或用户名）、失败次数、封禁状态（已封禁/正常）、最后失败时间。可逐条“删除”、“清除所有记录”或“刷新”。封禁规则见[访问控制](/guide/server/access-control.md)。

## 登录页与 IP 登记页

- 登录页：用户名、密码、验证码（开启 `open_captcha` 时；开启两步验证时 6 位动态码接在密码后面，开启验证码时也可接在验证码后面）、登录；开启 `allow_user_register` 时有“注册”入口，页脚有“IP 登记”入口。
- IP 登记页（无需登录）：显示“当前 IP”，输入“登记口令”（客户端的登记口令或 vkey；公钥 `public_vkey` 对所有客户端生效），选“有效期”（超过上限按上限），填验证码后点“登记”。用法见[访问控制](/guide/server/access-control.md)。
