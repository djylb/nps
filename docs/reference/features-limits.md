# 限制与统计

## 流量限制

支持客户端级流量限制，当该客户端入口流量与出口流量达到设定的总量后会拒绝服务
，域名代理会返回 404 页面，其他代理会拒绝连接,使用该功能需要在`nps.conf`中设置`allow_flow_limit`。

### 流量统计方式

全局、客户端、隧道和域名转发各级流量都按**单侧**统计：**入口流量**为访问者发往客户端的字节，**出口流量**为客户端返回访问者的字节，每个字节只计一次；**上下行流量**为两者之和。统计的是转发的内容，不含加密、压缩和多路复用的开销，也不含客户端与服务端之间的心跳等控制流量。

由于每个转发的字节都要经过“访问者 ↔ 服务器”和“服务器 ↔ 客户端”两段，服务器实际消耗的流量约为上下行流量的两倍，列表中的**实际消耗**即上下行流量 × 2。

流量限制默认按上下行流量判断；在`nps.conf`中设置`flow_limit_type=actual`后，**客户端**的流量限制改为按实际消耗判断，即同样的限制值可用的上下行流量减半。隧道和域名转发的流量限制始终按上下行流量判断。

## 带宽限制

支持客户端级带宽限制，带宽计算方式为入口和出口总和，权重均衡,使用该功能需要在`nps.conf`中设置`allow_rate_limit`。

### 全局带宽限制与转发流量统计

在**全局参数**页可以设置全局带宽限制（KB/s，0 为不限制），所有客户端的转发流量合计不超过该带宽，与各客户端自身的带宽限制同时生效，修改后对已建立的连接立即生效。全局带宽限制不受`allow_rate_limit`开关影响。和客户端带宽限制一样，空闲后的前 2 秒流量可以突发通过。

客户端列表上方会显示服务端的转发流量和当前速率：**流入**为访问者发往客户端的流量，**流出**为客户端返回访问者的流量，方便查看 VPS 上 nps 共计转发了多少流量。统计与客户端流量一起持久化到`conf/global.json`；点击列表上方的“清除流量”会同时清零。

## 时间限制

支持客户端级到期日期限制，到期后会拒绝连接，使用该功能需要在`nps.conf`中设置`allow_time_limit`。
支持随便填写日期格式自动识别（支持时间戳、注意系统时区），留空关闭。示例：2025-01-01（指定东八时区：2025-01-01 00:00:00 +0800 CST）

## 隧道与域名转发限速

隧道和域名转发支持独立配置上行、下行限速，单位 KB/s（1 KB/s = 1024 B/s），0 表示不限速。上行指访问者到目标服务，下行指目标服务到访问者。同一条目的所有连接共用各自方向的额度，并同时受客户端原有的双向合计限速、服务端全局限速约束；客户端 `rate_limit` 的含义不变，旧配置无需修改。

网页新增、编辑页面可设置限速，列表中的限速值可点击清空对应方向。客户端和隧道列表提供可排序的网速、上行网速、下行网速，默认只显示合计网速，可在列选择菜单开启另外两列。

通过 npc.conf 配置时，在对应隧道或域名段添加：

```ini
upload_limit=100
download_limit=500
```

这些限制和速度统计作用于经过 nps 转发的数据；P2P 直连流量不经过服务端，不计入服务端统计或限速。已有数据文件缺少上述字段时按不限速处理。

## 隧道连接数限制

可在隧道新增、编辑的限制设置中配置最大连接数，或在 npc.conf 的隧道段设置 `max_conn=10`。0（默认）表示不限，与客户端 `[common]` 段的 `max_conn` 总连接数限制同时生效，旧配置无需修改。列表详情中的最大连接数可点击清空。

TCP、混合代理、文件模式按访问连接计数，普通 UDP 按活跃转发会话计数，SOCKS5 UDP 跟随其 TCP 控制连接计数。达到上限时拒绝新连接，断开后释放名额。限额校验本身不主动关闭已有连接；网页编辑仍沿用原有的重启隧道行为。私密隧道的中继连接同样受限，P2P 直连不经过服务端，不受此限制。域名的连接数限制见[域名转发](/guide/tunnels/domain-forwarding.md)。

## 全局转发连接数限制

管理员可在“全局参数”设置最大转发连接数，0（默认）表示不限，页面同时显示当前占用数。该设置保存在全局数据文件中，重启后保留；旧文件未配置时不限。它与客户端和隧道连接数上限同时生效，任意一级达到上限都拒绝新转发，已有转发退出后释放名额。降低全局上限不会断开已有转发。

计数沿用客户端连接数的口径：TCP、HTTPS 透传按连接，UDP 按会话，SOCKS5 UDP 跟随控制连接，HTTP/HTTPS 域名转发按并发请求。npc 控制连接、管理网页和 P2P 直连不计入此项。

## 客户端最大连接数

为防止恶意大量长连接，影响服务端程序的稳定性，可以在web或客户端配置文件中为每个客户端设置最大连接数。该功能针对`socks5`、
`http正向代理`、`域名代理`、`tcp代理`、`udp代理`、`私密代理`生效,使用该功能需要在`nps.conf`中设置
`allow_connection_num_limit=true`。

## 客户端最大隧道数限制

nps支持对客户端的隧道数量进行限制，如需开启，请在`nps.conf`中设置`allow_tunnel_num_limit=true`。
