# UDP 隧道

## 这能解决什么

把内网机器的某个 UDP 端口，映射到公网服务器的一个 UDP 端口上，适合内网 DNS、游戏联机等。

示例：公网服务器 `203.0.113.10` 的 UDP `53` 转发到内网 DNS `192.168.1.10:53`。

## 操作步骤

1. 左侧菜单点“UDP 隧道”，点“新增”。
2. “客户端 ID”选内网机器上的客户端。
3. 在“监听与目标”里填：
   - 服务端端口：`53`；
   - 目标 (IP:端口)：`192.168.1.10:53`。
4. 点“新增”。
5. 在服务器防火墙放行 UDP `53`。

## 怎么验证

在任意一台能访问公网服务器的机器上：

```bash
nslookup www.example.com 203.0.113.10
```

能得到内网 DNS 的解析结果，说明通了。非 DNS 的服务，用对应的客户端程序连 `203.0.113.10` 的这个端口即可。

## 常见选项

UDP 隧道的字段与 [TCP 隧道](/guide/tunnels/tcp.md)基本相同，区别如下：

- 目标只有一个，不支持负载均衡，也不支持[健康检查](/guide/tunnels/health-check.md)。
- 最大连接数按活跃的转发会话计数，而不是按连接。
- “服务端端口”同样可以填端口范围。
