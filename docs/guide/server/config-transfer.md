# 导出与导入配置

管理员可以在“全局参数”页把客户端、隧道和域名导出为 JSON 文件，再导入到另一台 nps。

导出文件只用于在 0.x 版本的 nps 之间搬配置，不是完整备份，也不是迁移到新大版本的途径。

## 导出

点击“导出配置”，下载 `nps-config-<时间>.json`。接口为 `GET /global/export`。

- **文件含明文密钥**：vkey、登录密码、证书私钥等都在内，请妥善保管。
- 不包含配置文件发布的条目，也不包含全局名单和全局限制。

## 导入

选择文件后点击“导入配置”，接口为 `POST /global/import`（表单字段 `data` 为文件内容）。

- 所有条目**作为新条目加入并分配新 ID，不替换已有内容**。
- 整体校验：vkey、登记口令、Web 用户名、已启用隧道的端口、域名与现有内容或文件自身冲突，或名单规则有误时，整个文件被拒绝。
- 添加时才发现的冲突（如端口无法绑定）会撤销已添加的内容。
- 导入的条目流量从零开始，保留流量和时间限制。
- 关联到虚拟客户端（负数 ID）的条目要求目标服务器上有同一虚拟客户端。
- 文件格式版本不符时拒绝。

要在同一台服务器恢复，请先删除对应的客户端和条目，否则 vkey 冲突。
