# 多实例发布

同一 `vkey` 可以运行多个 npc，用配置文件发布相同的隧道（相同端口或密钥）或域名（相同域名和路径）：

- 新连接在发布该条目的实例间轮询，每个实例使用自己配置的目标；`bridge_select_mode` 不影响这些条目。
- 一个实例离线只移除它的路由，流量转到其余实例；最后一个实例离线后条目被移除。
- 目标以外的设置（限速、访问名单等）由所有实例共用，以最后发布的为准。
- HTTP 域名的轮询发生在建立后端连接时，复用中的后端连接仍留在原实例。
- 版本低于 0.32 的 npc 没有稳定的实例标识，其条目不区分实例，仍按 `bridge_select_mode` 选择。

Web 管理的隧道和域名不受影响。

一个实例的配置交换失败时只断开该实例，不影响同一 `vkey` 的其他实例；新实例加入不重启正在运行的隧道。

Web 管理的条目按 `bridge_select_mode` 选择实例：主备（`0`/`Primary`/`p`）、轮询（`1`/`RoundRobin`/`rr`）、随机（`2`/`Random`/`rand`）。

此功能到 1.0 不会原样保留，见[版本规则](../../getting-started/versioning.md)。
