# 客户端

npc 是装在内网机器上的客户端。它主动连接公网上的 nps 服务端，把内网服务带出去。

- [连接与系统服务](/guide/client/connect.md)：用网页给出的命令连上服务端，选择连接方式，安装为开机自启的服务。
- [启动链接与多条连接](/guide/client/launch.md)：一个 npc 连多个服务端，在本机开点对点访问端口，使用配置文件。
- [更新与维护](/guide/client/maintenance.md)：更新版本，查看日志，判断客户端是否在线。

查参数时看参考手册：[npc 命令行参数](/reference/npc-cli.md)、[启动链接与配置格式](/reference/npc-launch.md)、[npc.conf 配置](/reference/npc-config.md)。
